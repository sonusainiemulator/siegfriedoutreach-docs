# RULES.md — Documentation & Git Sync Guidelines

## 📌 Rules for Maintenance
- Build Verification: `npm run build` must pass with 0 errors before pushing.
- GitHub Sync: All local commits must be pushed immediately to `https://github.com/sonusainiemulator/siegfriedoutreach-docs.git` on the `main` branch.
- Interactive AI Assistant: Ensure `AiDocsAssistant.tsx` contains context for all newly added features.
