# AGENTS.md — Documentation Repository Directives

## 🎯 Mandatory Agent Instructions
1. **Always Auto-Push to GitHub**: Whenever any page or asset is updated in this documentation portal, always run `npm run build && git add . && git commit -m "docs: <summary>" && git push origin main`.
2. **Bilingual Requirement**: Maintain high-quality English and Hindi walkthroughs on every feature.
3. **Real-World Case Studies**: Every feature must include concrete industry use cases and practical examples (E-Commerce, Agencies, Healthcare, Real Estate, EdTech, SaaS).
