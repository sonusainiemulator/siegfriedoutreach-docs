## 🔗 Connecting Social Networks

Siegfried Outreach supports official direct API integrations with all major social networks.

<Tabs items={['English Guide', 'हिंदी गाइड']}>
  <Tab value="English Guide">
    ### Supported Networks & Required Permissions

    | Network | Supported Post Types | Token Validity |
    | :--- | :--- | :--- |
    | **Instagram** | Posts, Carousels, Reels, Stories | 60 Days (Auto-refreshed) |
    | **YouTube** | Videos (16:9), Shorts (9:16) | Long-lived OAuth |
    | **X (Twitter)** | Tweets, Threads, Media Posts | OAuth 2.0 PKCE |
    | **TikTok** | Short-form Videos (9:16) | 365 Days |
    | **LinkedIn** | Single Posts, Multi-Image, Articles | 60 Days |
    | **Facebook** | Page Posts, Reels, Stories | Long-lived Page Token |
    | **Pinterest** | Pins, Idea Pins, Boards | Permanent Refresh Token |
    | **Reddit** | Subreddit Submissions, Text/Media | OAuth 2.0 |
    | **WordPress** | Blog Posts, Articles, Featured Media | REST API App Password |

    ### Connection Steps
    1. Navigate to **Social Accounts** from the left navigation menu.
    2. Click **Add Account** and select the network you wish to link.
    3. You will be redirected to the provider's official OAuth consent screen.
    4. Grant the requested publishing permissions and confirm.
    5. Your account name, avatar, and follower stats will automatically sync.
  </Tab>

  <Tab value="हिंदी गाइड">
    ### समर्थित प्लेटफ़ॉर्म्स और परमिशन

    | प्लेटफ़ॉर्म | समर्थित पोस्ट प्रकार | टोकन वैधता |
    | :--- | :--- | :--- |
    | **Instagram** | पोस्ट, कैरोसेल, रील्स, स्टोरीज़ | 60 दिन (ऑटो-रिफ्रेश) |
    | **YouTube** | वीडियो (16:9), शॉर्ट्स (9:16) | लॉन्ग-लिव्ड OAuth |
    | **X (Twitter)** | ट्वीट्स, थ्रेड्स, मीडिया पोस्ट्स | OAuth 2.0 PKCE |
    | **TikTok** | शॉर्ट-फॉर्म वीडियो (9:16) | 365 दिन |
    | **LinkedIn** | सिंगल पोस्ट, मल्टी-इमेज, आर्टिकल | 60 दिन |
    | **Facebook** | पेज पोस्ट्स, रील्स, स्टोरीज़ | लॉन्ग-लिव्ड पेज टोकन |
    | **Pinterest** | पिन्स, बोर्ड्स, इमेजेस | परमानेंट रिफ्रेश टोकन |
    | **Reddit** | सबरेडिट पोस्ट्स, टेक्स्ट/मीडिया | OAuth 2.0 |
    | **WordPress** | ब्लॉग पोस्ट्स, आर्टिकल्स, फीचर्ड इमेज | REST API पासवर्ड |

    ### कनेक्ट करने के स्टेप्स
    1. लेफ्ट साइडबार मेनू से **Social Accounts** पर क्लिक करें।
    2. **Add Account** बटन दबाएं और अपना मनचाहा सोशल नेटवर्क चुने।
    3. ऑफिशियल लॉगिन और परमिशन स्क्रीन पर अप्रूव करें।
    4. अप्रूवल के बाद आपका अकाउंट, प्रोफाइल फोटो और फॉलोअर्स काउंट तुरंत सिंक हो जाएंगे।
  </Tab>
</Tabs>

  <Tab value="English Case Study">
    ### 📱 1. Multi-Brand Agency Managing 15 Client Workspaces
    - **Scenario**: A social media management agency needs to manage distinct client accounts (Facebook Pages, Pinterest boards, Subreddits, and WordPress blogs) without mixing credentials.
    - **Solution**: The agency connects each client's specific Page tokens and Pinterest boards under isolated social account profiles.
    - **Outcome**: Zero cross-posting errors and instant 1-click channel switching.
