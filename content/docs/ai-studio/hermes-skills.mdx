# 🤖 Hermes Autonomous Skills (`/ai-agent-skills`)

**Hermes Skills** provide pre-built action capabilities that allow AI agents to autonomously query databases, manage CRM records, execute broadcast campaigns, generate invoices, and publish social media content.

<Tabs items={['English Guide', 'हिंदी गाइड']}>
  <Tab value="English Guide">
    ### 🛠️ Built-in Skill Modules:
    - **Social Publishing Skill**: Autonomous multi-channel posting, schedule queue inspection, and telemetry retry triggers.
    - **CRM & Contact Skill**: Search customer profiles, update lead statuses, and fetch transaction history.
    - **Broadcast Dispatch Skill**: Trigger WhatsApp Cloud API templates and Telegram broadcast notifications.
    - **Analytics & Report Skill**: Generate weekly executive KPIs and export raw data summaries.
  </Tab>

  <Tab value="हिंदी गाइड">
    ### 🛠️ हर्मीस स्किल्स के काम:
    - **ऑटो सोशल पब्लिशिंग**: AI एजेंट्स को सोशल मीडिया पर पोस्ट करने और मॉनिटर करने की क्षमता देता है।
    - **CRM डेटा सर्च**: कस्टमर डिटेल्स और लीड्स को चेक करना।
    - **ब्रॉडकास्ट ट्रिगर**: व्हाट्सएप और टेलीग्राम पर मैसेज भेजना।
  </Tab>
