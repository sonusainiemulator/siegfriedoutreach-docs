# 💻 AI Codex (`/ai-codex`)

**AI Codex** is an AI coding engine capable of writing, debugging, and explaining code across 30+ programming languages (TypeScript, React, Next.js, Node.js, Python, PHP, Java, SQL, Rust, Go, CSS/HTML).

<Tabs items={['English Guide', 'हिंदी गाइड']}>
  <Tab value="English Guide">
    ### 🛠️ Use Cases:
    - **Code Generation**: Build components, API routes, database schemas, and algorithms from natural language prompts.
    - **Bug Diagnostic & Fixes**: Paste broken code or terminal error traces to receive pinpoint root-cause explanations and fixed code snippets.
    - **Code Modernization & Refactoring**: Optimize performance, convert JavaScript to TypeScript, or upgrade legacy code.
    - **Unit & Integration Tests**: Generate Jest, PyTest, or Mocha test cases.

    ### 🚀 How to Use:
    1. Go to **AI Tools ➔ AI Codex** (`/ai-codex`).
    2. Select the **Target Programming Language** from the dropdown.
    3. Type your instructions (e.g. *"Create a Next.js server action for JWT authentication"*) or paste existing code.
    4. Click **Generate Code**.
    5. Use the 1-click **Copy Code** button or test in your project.
  </Tab>

  <Tab value="हिंदी गाइड">
    ### 🛠️ कोडेक्स के मुख्य काम:
    - **कोड बनाना**: बस बताएं क्या बनाना है (जैसे *"MongoDB के लिए REST API बनाओ"*), AI पूरा कोड लिख देगा।
    - **बग और एरर फिक्स**: एरर कोड पेस्ट करें, AI कारण बताकर सही कोड देगा।
    - **कोड इम्प्रूवमेंट**: पुराने कोड को मॉडर्न और फास्ट बनाएं।
  </Tab>
