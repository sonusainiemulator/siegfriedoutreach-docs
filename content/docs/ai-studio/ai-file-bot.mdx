# 📄 AI File Bot (`/ai-file-bot`)

Upload documents (PDF, DOCX, CSV, XLSX, TXT) and interactively query their contents, extract key data tables, summarize contracts, and perform calculations.

<Tabs items={['English Guide', 'हिंदी गाइड']}>
  <Tab value="English Guide">
    ### 📂 Supported Workflows:
    - **Legal Contracts**: Ask questions like *"What is the termination clause and penalty amount?"*
    - **Financial Spreadsheets**: Inquire *"What was the highest grossing product in Q2?"*
    - **Research Papers & Manuals**: Generate instant executive summaries and bulleted key takeaways.

    ### 🚀 How to Use:
    1. Navigate to **AI Tools ➔ AI File Bot** (`/ai-file-bot`).
    2. Upload your file (PDF, Excel, Word).
    3. The AI processes and indexes the file in seconds.
    4. Ask any question in natural language in the chat input.
  </Tab>

  <Tab value="हिंदी गाइड">
    ### 📂 फाइल बॉट के उपयोग:
    - कोई भी PDF, Word या Excel शीट अपलोड करें और उससे सीधे सवाल पूछें।
    - बड़ी-बड़ी रिपोर्ट्स की मुख्य बातें (Summary) 5 सेकंड में निकालें।
  </Tab>
</Tabs>
